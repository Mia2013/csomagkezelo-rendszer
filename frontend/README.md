# Frontend

A `frontend` mappában:

```text
npm ci
npm run dev
```

Megnyitás: http://localhost:5173. A backend fusson a https://localhost:7259 címen.
Az `npm ci` első indításkor és a függőségek változásakor szükséges.

Tesztek és ellenőrzés: `npm test`, `npm run lint`, `npm run build`.
A backend indítása a [projekt README-jében](../README.md) található.
